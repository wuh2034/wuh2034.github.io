Stereo Reconstruction from Scratch (C++ / OpenCV)

Classical two-view geometry implemented end to end in C++ — down to a hand-written rectification and disparity solver, rather than calling a library and hoping.

Code

Overview

A full stereo reconstruction pipeline built on OpenCV and Eigen, taking a pair of images from the Middlebury Stereo Dataset all the way to rectified images, disparity maps, depth maps, point clouds and meshes. The point of the project was to implement the classical machinery rather than to consume it: both a library path and a hand-rolled path exist side by side, which makes the failure modes of each visible.

Pipeline

  • Preprocessing. High-resolution Middlebury pairs with the dataset's intrinsics and extrinsics, converted to greyscale and prepared for geometric processing.
  • Features. Keypoints and descriptors from ORB, SIFT and BRISK, matched with KNN and filtered by a ratio test — three detectors so their behaviour can be compared on the same scene.
  • Two-view geometry. RANSAC estimates the fundamental matrix from the matches and counts inliers; the essential matrix follows from the intrinsics and is decomposed into relative rotation and translation.
  • Rectification, two ways. An uncalibrated path via cv::stereoRectifyUncalibrated, and a calibrated path implemented from scratch — projection matrices built from the intrinsics and a custom myWarpPerspective warp.
  • Disparity. OpenCV's StereoSGBM on the uncalibrated path (with CLAHE contrast enhancement), and a custom FastSGBM implementation on the calibrated path.
  • 3D output. Triangulation to a sparse point cloud, dense correspondence and depth estimation on top of it, then visualisation and mesh generation with Open3D.

Code

Single-binary CMake project, with a Docker setup and the Middlebury scenes included: wuh2034/stereo-reconstruction.
